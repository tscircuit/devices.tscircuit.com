A carrier for the 2.8-inch non-touch ER-TFT028A2-4 bare IPS panel.

<CadDownloads board="small-ips" />

**Modeled component height: approximately 3.3 mm above the component-side PCB surface.** The CAD files show the populated carrier. Allow separate space for the panel and flex cable.

## Usage

Use the panel as a compact desktop status screen. With power removed, verify the contact face and pin 1 before seating the ribbon. Mount the panel independently of the PCB and leave room to open the latch.

## Protocol

**Four-wire SPI** · interface II (IM3…IM0 = 1110). This prototype has no published USB command set. The table describes the interface on the PCB.

| Operation | Request or signal | Result |
| --- | --- | --- |
| Reset | Pulse the panel reset line. | Returns the panel to its startup state. |
| Send command | Select the panel with CS and use D/C to select command bytes. Clock bytes onto MOSI. | Selects a panel operation. |
| Write pixels | Initialize the panel, set its address window, then transfer pixel bytes in data mode. | Updates that rectangle. |
| Dim backlight | Adjust backlight PWM duty cycle. | Changes illumination. |

## Mounting

The PCB measures **36 × 38 mm**, with **4 × Ø2.2 mm** clearance holes for M2 screws. The centre-to-centre spacing is **30 × 10 mm**. Orient the component side with the **J1 USB-C port at the bottom**. Measure right and up from the **lower-left corner of the PCB** in the component-side view. The hole centres are at X = 3, 33 mm and Y = 14, 24 mm.
