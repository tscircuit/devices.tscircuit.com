A roller-lever switch for detecting when a moving part reaches a stop.

## Mounting

The PCB measures **24 × 30 mm**, with **4 × Ø2.2 mm** clearance holes for M2 screws. The centre-to-centre spacing is **19 × 25 mm**. Orient the component side with the **J1 USB-C port at the bottom**. Measure right and up from the **lower-left corner of the PCB** in the component-side view. The hole centres are at X = 2.5, 21.5 mm and Y = 2.5, 27.5 mm.

## Usage

Choose **Add device → Limit switch**. Press the lever until it clicks, then release it. Place the stop so it trips the lever before the end of travel. The normally closed contact changes the sense of CTS compared with the pushbutton.

## Protocol

Read the USB modem-status signal **CTS**. An asserted signal means **Released** and a deasserted signal means **Pressed**. The contact sends its state through this signal without writing serial bytes.

With Web Serial, open at 9600 baud with flow control disabled, set DTR low, and read `(await port.getSignals()).clearToSend`. With WebUSB, issue a device-recipient vendor IN request with request `0x95`, value `0x0706`, index `0`, and length `2`. CTS is asserted when bit 0 of the first byte is clear. The console polls every 10 ms and accepts a state after 20 ms of stability.
