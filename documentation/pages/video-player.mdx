A microSD-backed controller designed for local video playback on the 3.5-inch ER-TFT035IPS-6 panel.

<CadDownloads board="video-player" />

**Modeled component height: approximately 3.3 mm above the component-side PCB surface.** The CAD files show the populated carrier. Allow separate space for the panel and flex cable. The microSD socket also projects below the board.

## Usage

Fit the bare panel and a microSD card, leaving access to the socket on the reverse side of the PCB. The design targets 30 full frames per second. Playback at that rate still needs firmware and an end-to-end measurement on hardware.

## Protocol

**Four-bit SD and 16-bit i80 display bus.** This prototype has no published USB command set. The table describes the interface on the PCB.

| Operation | Request or signal | Result |
| --- | --- | --- |
| Read media | Transfer data from microSD over the four-bit SD bus. | Supplies local video data to the controller. |
| Select panel operation | Set D/C to command mode and strobe the write line. | Sends a panel command. |
| Write pixels | Use data mode and clock one RGB565 pixel per write strobe. | A 320 × 480 frame consumes 307200 bytes. |

The 30 fps design target requires 9.216 MB/s of pixel data. The USB frame commands documented for the flex display apply to that board’s firmware.

## Mounting

The PCB measures **48 × 48 mm**, with **4 × Ø2.2 mm** clearance holes for M2 screws. The centre-to-centre spacing is **40 × 30 mm**. Orient the component side with the **J1 USB-C port at the bottom**. Measure right and up from the **lower-left corner of the PCB** in the component-side view. The hole centres are at X = 4, 44 mm and Y = 9, 39 mm.
