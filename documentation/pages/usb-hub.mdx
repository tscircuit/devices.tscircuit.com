A computer-powered four-port USB 2.0 hub for connecting multiple desktop modules.

## Mounting

The PCB measures **44 × 42 mm**, with **4 × Ø2.2 mm** clearance holes for M2 screws. The centre-to-centre spacing is **38 × 10 mm**. Orient the component side with the **J1 USB-C port at the bottom**. Measure right and up from the **lower-left corner of the PCB** in the component-side view. The hole centres are at X = 3, 41 mm and Y = 16, 26 mm.

## Usage

Connect the upstream USB-C port to a computer with a data cable, then plug the peripherals into the four downstream ports. Allow up to 100 mA per downstream module in this design. Add each supported peripheral in the console. Leave clearance in the enclosure for all five plugs.

## Protocol

The operating system enumerates the board using the standard USB 2.0 hub class. The host reads the hub descriptor, receives port-change notifications on the interrupt endpoint and uses class requests to query port status and reset newly attached devices. Each peripheral then enumerates separately with its own protocol. The hub requires no serial commands or console card.
