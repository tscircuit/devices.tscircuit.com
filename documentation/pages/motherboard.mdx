The board carries a directly mounted RP2350A, 16 MB of flash and a 12 MHz crystal. It hosts up to four USB devices through the onboard hub. J2–J5 are the four device sockets. The included program lets a potentiometer select three drawings on a flex display.

## Usage

Supply regulated 5 V and ground at the underside power pads. Slide **POWER** to **ON** on the same edge as J1. Switching it **OFF** powers down the processor, hub and all four device ports. The computer can still power the console interface. Connect a potentiometer and a flex display to any two of the four downstream ports. Turn the knob to select a circle, diagonal stripe or checkerboard. The controller starts on product power and runs with the computer unplugged.

Each downstream device has a 100 mA design budget. The example discovers USB CDC serial devices and supports the potentiometer and flex display. The distance sensor and contact-switch boards require additional host drivers.

## Programming and USB modes

Keep product power **ON** in both modes. Inside the enclosure, a miniature two-position service slider selects RUN or PROGRAM. Disconnect the computer cable before moving it.

| Service slider | J1 computer port | Four device ports |
| --- | --- | --- |
| **RUN** | 115200-baud console. Select **Add device → RP2350 USB Motherboard**. | The RP2350 hosts devices on J2–J5. |
| **PROGRAM** | Direct USB connection to the RP2350 for a UF2 update. | The hub is disconnected from the processor. |

1. Select **PROGRAM** and connect J1 to your computer. Firmware 1.1.0 enters the USB bootloader automatically.
2. Copy the [motherboard UF2](https://github.com/tscircuit/devices.tscircuit.com/releases/download/direct-rp2350a-switches-v1/rp2350-motherboard-1.1.0.uf2) to the **RP2350** drive.
3. Disconnect J1, select **RUN**, and press **RESET** to start the program.

**Recovery with blank flash or custom firmware.** With J1 unplugged and PROGRAM selected, hold **BOOT**, tap **RESET**, then release **BOOT** and reconnect J1.

**SWD.** The underside pads provide 3.3 V reference, SWDIO, SWCLK and ground. Apply product power and select RUN to debug the example. [Download the SWD ELF](https://github.com/tscircuit/devices.tscircuit.com/releases/download/direct-rp2350a-switches-v1/motherboard.elf)

This prototype revision awaits first-article power and USB testing. Earlier boards fitted with a processor module use SWD for programming.

## Protocol

Open the computer service port at 115200 baud. Send one ASCII command per line ending in LF.

| Command | Purpose | Reply |
| --- | --- | --- |
| `id` | Identify the controller. | `DEVICE tscircuit motherboard 1.1.0` |
| `help` | List commands. | One line of command names. |
| `devices` | List the connected serial interfaces. | One `PORT` line per interface, followed by `OK`. |
| `status` | Read the selected drawing. | `SCENE 1`, `2` or `3`. Zero means the controller is waiting for a reading. |

## Mounting

The PCB is **80 × 46 × 1.6 mm**. All components mount on top. Both switches rise **1.4 mm** above the PCB. The tallest assembled parts rise **5.4 mm**. The service slider sits inside the enclosure. Give the edge-facing POWER slider an opening on the same side as J1 and allow 1.5 mm of sliding travel. The four Ø2.2 mm holes accept M2 screws on a **70 × 40 mm** grid. With the downstream ports at the top, the hole centres are X = 2 and 72 mm, Y = 3 and 43 mm, measured from the lower-left corner. Allow access underneath for the product power wires and programming pads.
