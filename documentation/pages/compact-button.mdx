**Actuator-tip height: 12 mm nominal above the component-side PCB surface** with the button released. Leave room for the stem to move freely through the lid.

## Usage

Use the two holes along the side of the board to leave the centre free for the actuator. Check the revision before printing a mount. This prototype uses a 20 × 26 mm board and 10 mm between its two holes. The original pushbutton uses four holes.

## Protocol

Choose **Button** in the console for this prototype. **USB contact input.** Read the clear-to-send signal (CTS) to get the switch state.

| Operation | Request or signal | Result |
| --- | --- | --- |
| Open with Web Serial | `port.open({baudRate: 9600, flowControl: "none"})` | Opens the port for polling. |
| Set DTR low | `port.setSignals({dataTerminalReady: false})` | Configures the serial control line. |
| Read with Web Serial | `(await port.getSignals()).clearToSend` | `true` = **Pressed**, `false` = **Released**. |
| Read with WebUSB | Vendor IN request to the device: `0x95`, value `0x0706`, index `0`, length `2`. | Bit 0 of byte 0: `0` = **Pressed**, `1` = **Released**. |

Use either the Web Serial or WebUSB path. The console polls every 10 ms and displays a change after 20 ms of stable readings.

[Protocol implementation](https://github.com/tscircuit/devices.tscircuit.com/blob/main/web/contact-switch.js)

## Mounting

The PCB measures **20 × 26 mm**, with **2 × Ø2.2 mm** clearance holes for M2 screws. The centre-to-centre spacing is **10 mm**. Orient the component side with the **J1 USB-C port at the bottom**. Measure right and up from the **lower-left corner of the PCB** in the component-side view. The hole centres are at X = 2.5 mm and Y = 7, 17 mm.
