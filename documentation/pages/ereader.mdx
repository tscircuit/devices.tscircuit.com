A carrier for the black-and-white 5.83-inch ER-EPD0583-1B bare e-paper panel.

## Usage

Use it for a desk sign, schedule, or other image that changes occasionally. Mount the glass on its own support and leave slack at the ribbon. The drawing dimensions apply to the controller PCB.

## Protocol

**Four-wire SPI** · black-and-white e-paper. This prototype has no published USB command set. The table describes the interface on the PCB.

| Operation | Request or signal | Result |
| --- | --- | --- |
| Reset | Pulse the panel reset line. | Prepares the controller for initialization. |
| Load image | Select the panel with CS. Use D/C to send an image-memory command followed by data. | Stages image data in panel memory. |
| Refresh | Send the panel refresh command. | Updates the glass using the external boost stage. |
| Wait | Monitor BUSY. | Start the next update once the panel is idle. |

## Mounting

The PCB measures **36 × 38 mm**, with **4 × Ø2.2 mm** clearance holes for M2 screws. The centre-to-centre spacing is **30 × 20 mm**. Orient the component side with the **J1 USB-C port at the bottom**. Measure right and up from the **lower-left corner of the PCB** in the component-side view. The hole centres are at X = 3, 33 mm and Y = 9, 29 mm.
